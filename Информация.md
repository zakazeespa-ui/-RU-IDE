🐍 Питонка IDE (v1.0.0) — Суверенная среда разработки и обучения
Официальное позиционирование: Высокопроизводительный отечественный аналог зарубежных сред разработки (Thonny, IDLE, VS Code), созданный на базе PyQt6 и C++ движка Scintilla, полностью оптимизированный под требования российских образовательных стандартов (ОГЭ/ЕГЭ) и кросс-платформенную работу.

🎯 ЧАСТЬ 1: Для пользователей (Почему её ЗАХОТЯТ скачать все)
Устал от аскетичного и неудобного IDLE? Надоел Thonny, который зависает на простейших алгоритмах и выглядит как программа из 2000-х? Встречай Питонку — среду разработки нового поколения, созданную программистами для программистов.

🔥 Ключевые фичи, которых нет у конкурентов:
Ультимативный Web-Режим (F5 для всего): Пишешь фронтенд? Питонка — это больше не просто Python IDE. Открывай файлы .html, .js, .css, нажимай F5, и среда сама мгновенно запустит твой интерактивный сайт в браузере без каких-либо костылей и сторонних серверов.

Шеринг кода в один клик (Ctrl + Shift + C): Нашел крутое решение или хочешь показать баг другу? Нажми комбинацию клавиш — Питонка автоматически закодирует твой код в защищенный base64-архив и сгенерирует прямую веб-ссылку. Никаких флешек!

Встроенный Черновик (Scratchpad): Нужно быстро набросать циклы или проверить регулярку? Тебе не нужно создавать кучу файлов test1.py, test2.py на рабочем столе. Используй изолированный черновик, который автоматически сохраняет твоё состояние между перезапусками IDE через безопасный реестр QSettings.

Умный анализ переменных и интерактивный терминал: Визуальное дерево памяти (QTableWidget) в реальном времени показывает типы данных, значения списков и объектов. Идеально для отладки сложных 2D-игр или тяжелых вычислений.

Дизайн, который не выжигает глаза: Полная нативная интеграция трендовой палитры Catppuccin Mocha. Идеальный баланс контраста для работы в ночное время суток.

🏛️ ЧАСТЬ 2: Для государства и министерств (Почему это идеальный суверенный софт)
В условиях жесткого курса на импортозамещение и цифровой суверенитет, образовательный сектор остро нуждается в независимом ПО. Использование эстонского редактора Thonny или американского VS Code в учебных классах — это стратегический риск. Питонка IDE решает эту проблему.

🛡️ Преимущества для включения в Реестр отечественного ПО:
100% Локальная автономность и информационная безопасность:
В отличие от зарубежных аналогов, Питонка спроектирована по принципу Air-Gap (способность полноценно функционировать в полностью изолированных компьютерных классах без доступа к сети Интернет). Программа имеет локальный кэш, встроенные парсеры и автономную систему обработки ошибок, что исключает утечку метаданных учащихся на зарубежные сервера.

Прямая интеграция под задачи государственной итоговой аттестации (ОГЭ/ЕГЭ):
Ни одна зарубежная среда разработки «из коробки» не адаптирована под специфику российских экзаменов по информатике. Питонка включает в себя изолированную подсистему быстрых шаблонов решений (snippets.json) для типовых алгоритмических задач повышенной сложности (Задания №8, №15, №17, №23). Это готовый инструмент для стандартизации рабочих мест КЕГЭ.

Экстремальная легковесность для школьного оборудования:
Благодаря использованию ядра Scintilla (написанного на C++) и оптимизированного графического слоя PyQt6, среда потребляет до 5 раз меньше оперативной памяти, чем аналоги на базе Electron (VS Code) или Java (PyCharm). Она обеспечивает стабильные 60 FPS интерфейса даже на устаревшей материально-технической базе сельских школ.

Готовность к миграции на российские ОС (Astra Linux, ALT Linux, РЕД ОС):
Архитектура исходного кода (main.py, logic_editor.py, logic_terminal.py) абстрагирована от системных вызовов Windows. Логика путей инкапсулирована внутри защищенного метода get_base_path() с использованием механизма sys._MEIPASS. Это позволяет бесшовно упаковывать среду в нативные .deb и .rpm пакеты для российских Linux-дистрибутивов.
